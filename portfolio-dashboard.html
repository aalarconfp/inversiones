Overview

Managing investments across two countries means dealing with two currencies, multiple brokers, and data scattered across different apps and files. This dashboard brings everything together in one place — a single Excel workbook that gives a clear, up-to-date picture of the entire portfolio at a glance.

It covers both Colombian equities (BVC) and US equities (NYSE), automatically converting between pesos and dollars using the live exchange rate, and adjusting returns for inflation so the numbers reflect real purchasing power — not just nominal gains.

An automated data pipeline (built with Power Query and Power Pivot) pulls from multiple sources and refreshes the entire model in one click — no manual copy-pasting, no reconciliation errors.

Supports dual equity markets and multiple brokerage accounts. Designed to accommodate alternative investments with minor configuration adjustments.

Data Sources & Pipeline

All data flows in automatically from five sources. Each source feeds a specific layer of the analysis — from live positions and returns, to exchange rates, inflation figures, and price targets.

  • Portfolio Performance (app) — Main data source: position-level reports covering holdings, market values, gains/losses, dividends, fees, and returns separately for Colombian (COP) and US (USD) positions.
  • Exchange Rate & Colombian Inflation — From Banco de la República. Live COP/USD rate translates all positions to a single currency; the IPC inflation index calculates real returns on Colombian holdings.

  • Sector & Industry Data — External files classifying each stock by sector and industry, enabling portfolio breakdowns by market segment.
  • Price Targets — Valuation files for both markets with target prices, fair value estimates, buy thresholds, and risk levels per position.

What This Dashboard Solves

A portfolio split across two countries, two currencies, and multiple brokers produces no natural single view of performance. Piecing it together manually is slow, inconsistent, and easy to get wrong.

  • One view, two markets — Colombian and US positions side-by-side, converted to a common currency via the live exchange rate
  • Real returns — Performance figures adjusted for inflation — you see actual gains, not numbers inflated by price levels
  • Strategy built in — Every position shows its price target, distance from fair value, and buy/cut thresholds
  • One-click refresh — All data sources update automatically; no copy-pasting between accounts
  • Easy to extend — Adding a new stock, broker, or asset class only requires updating source files

Built for an individual investor managing positions across BVC and NYSE. The same structure scales to additional markets, currencies, or asset classes by connecting new data sources.
