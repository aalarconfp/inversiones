✦ Sobre el proyecto

Inversiones es un proyecto personal enfocado en educación financiera, finanzas personales y análisis de inversiones, con herramientas web diseñadas para convertir conceptos financieros en recursos prácticos.

El proyecto está orientado principalmente al contexto de Colombia y LATAM y reúne guías, dashboards, screeners y calculadoras en una única colección.

Objetivo: facilitar el aprendizaje y el análisis financiero mediante herramientas simples, visuales y accionables.


🎯 Filosofía

El proyecto busca que cada herramienta responda una pregunta concreta:

¿QUÉ QUIERO ENTENDER?
        ↓
¿QUÉ DATOS NECESITO?
        ↓
¿CÓMO LOS ANALIZO?
        ↓
¿QUÉ RIESGOS EXISTEN?
        ↓
¿QUÉ DECISIÓN PUEDO TOMAR?

La intención no es sustituir el análisis financiero profesional, sino crear herramientas que permitan entender mejor los datos antes de tomar decisiones.

⚠️ Disclaimer

Este proyecto tiene una finalidad educativa e informativa.

El contenido y las herramientas no constituyen asesoría financiera, tributaria o legal personalizada ni representan una recomendación de compra o venta de activos.

Las decisiones de inversión deben considerar la situación particular de cada persona, los riesgos involucrados y la información vigente de las fuentes correspondientes.
